# Functional Requirements

## 1. Question & Answer

The system should accept student questions and generate AI-based answers.

## 2. Concept Explanation

The system should explain difficult concepts in simple language.

## 3. Quiz Generation

The system should generate quiz questions based on a selected topic.

## 4. Text Summarization

The system should summarize lengthy educational content.

## 5. Learning Recommendations

The system should provide suitable learning recommendations.
