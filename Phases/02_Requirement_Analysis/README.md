# Phase 2 – Requirement Analysis

This phase identifies the functional, non-functional, hardware,
and software requirements of EduGenie.

## Functional Requirements

- Question and Answer
- Concept Explanation
- Quiz Generation
- Text Summarization
- Learning Recommendations

## Non-Functional Requirements

- Usability
- Performance
- Reliability
- Security
- Scalability

## Software Requirements

- Python
- FastAPI
- Google Gemini API
- HTML
- CSS
- JavaScript
- Visual Studio Code
- Git
- GitHub

## Hardware Requirements

- Computer/Laptop
- Minimum 4 GB RAM
- Internet connection
- Standard processor
