# Phase 5 – Project Development

## Development

EduGenie was developed using Python, FastAPI, HTML, CSS, JavaScript,
and Google Gemini API.

## Backend

FastAPI is used to handle API requests and communicate with Google Gemini.

## AI Integration

Google Gemini is used to generate intelligent educational responses.

## Frontend

HTML, CSS, and JavaScript are used to create the user interface.

## Main API Endpoints

- /qa
- /explain
- /quiz
- /summarize
- /learn/recommendations

## Main Features

- Question & Answer
- Concept Explanation
- Quiz Generation
- Text Summarization
- Learning Recommendations
