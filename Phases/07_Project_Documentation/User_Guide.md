# EduGenie User Guide

## Step 1
Start the FastAPI server.

## Step 2
Open the EduGenie application in a browser.

## Step 3
Select the required learning feature.

## Step 4
Enter your question or topic.

## Step 5
Click the Generate button.

## Step 6
View the AI-generated response.

## Available Features

- Q&A
- Concept Explanation
- Quiz
- Summarization
- Learning Recommendations
