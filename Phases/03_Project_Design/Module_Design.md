# Module Design

## Q&A Module
File: qna.py

Purpose:
Provides answers to student questions.

## Explanation Module
File: explanation_module.py

Purpose:
Explains difficult concepts in simple language.

## Quiz Module
File: quiz_module.py

Purpose:
Generates practice quiz questions.

## Summary Module
File: summary_module.py

Purpose:
Summarizes lengthy educational content.

## Learning Path Module
File: learning_path.py

Purpose:
Provides learning recommendations.

## Gemini Client
File: gemini_client.py

Purpose:
Connects the application with Google Gemini API.
